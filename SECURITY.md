# Security Policy

Kadmos is a Developer Preview (v0.x). Security fixes are evaluated on the current development branch; no historical version support window is promised yet.

Please report suspected vulnerabilities privately to [security@substratum.io](mailto:security@substratum.io) or through [GitHub private vulnerability reporting](https://github.com/substratum-labs/kadmos/security/advisories/new). Include affected versions or commits, a minimal reproduction, impact, and a safe way to contact you. Do not post exploit details in a public issue or pull request before coordinated disclosure.

Maintainers will acknowledge reports, investigate and reproduce them, coordinate a fix and disclosure timeline with the reporter, and credit reporters who want attribution. If a report concerns physical side effects, note that Kadmos gatekeepers are in-process decision engines: the host or effect broker must enforce their verdicts.
