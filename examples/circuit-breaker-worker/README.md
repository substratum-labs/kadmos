# Kadmos Circuit-Breaking Task Worker (Example Project)

A complete, self-contained microproject built on the **Kadmos World & Fabric Bipartite Architecture**.

## Project Structure

```
circuit-breaker-worker/
├── PRD.md                       # Natural language requirements document
├── spec/
│   └── task_worker.world.yaml   # Formal World IR specification
├── src/
│   ├── world/                   # AUTO-GENERATED BY `kadmos compile`
│   │   ├── ports.d.ts           # Compile-time TypeScript membrane & contracts
│   │   └── world_checker.ts     # Deterministic in-process runtime gatekeeper
│   ├── fabric_worker.ts         # Asynchronous worker logic (Untrusted Fabric)
│   └── index.ts                 # Runnable entry point demonstrating scenarios
├── package.json
└── tsconfig.json
```

## How It Was Built with Kadmos

1. **Inference**: Extracted lifecycle, retry context, and safety invariants from `PRD.md`:
   ```bash
   node ../../bin/kadmos.js infer PRD.md
   ```
2. **Specification**: Authored the formal FSM and invariants in `spec/task_worker.world.yaml`.
3. **Compilation**: Compiled the World specification into TypeScript:
   ```bash
   node ../../bin/kadmos.js compile spec/task_worker.world.yaml --out src/world
   ```
4. **Execution**: Fabric worker is constrained by the generated `WorldChecker`.

## Running the Project

```bash
# Build TypeScript
npm run build

# Run scenarios
npm run start
```

## Scenarios Demonstrated

1. **Adversarial / Buggy Interception**: Intercepts illegal transitions from `IDLE` before execution.
2. **Transient Failure & Backoff**: Handles retry loops, progressive backoff, and clean completion.
3. **Circuit Breaker Trip**: Enforces `max_retries = 3` boundary, trips to `CIRCUIT_BROKEN`, and issues PagerDuty alert.
4. **Terminal State Lockdown**: Prohibits further actions after circuit trip.
